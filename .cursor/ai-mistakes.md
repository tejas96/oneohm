# AI Mistakes Log — OneOhm EPC (Web + Backend)

Read before every task. Max 2 lines per entry. Append-only.

---

- **2026-03-09 — Quote versioning: client-side state fragility**: Relied on React `useState` (`savedQuoteId`) for cross-navigation versioning. State resets on unmount/remount → always created v1. → Move versioning logic to backend auto-detection; never rely on client-side state for persistent business logic.
- **2026-03-09 — Quote number generation ignores soft-deleted rows**: `generateQuoteNumber` used TypeORM query that auto-filters `deleted_at IS NULL`, skipping soft-deleted quote numbers. Unique constraint then rejected duplicates. → Always use `.withDeleted()` when querying for sequence/unique-value generation.
- **2026-03-09 — MAX_VERSIONS_REACHED infinite archive loop**: After archiving one quote, auto-detect picked another maxed quote, causing an endless error loop with 12 test quotes. → `findRevisableQuote` must filter by capacity (`currentVersion < maxVersions`); when explicit `quoteId` is maxed, throw immediately instead of falling through.
- **2026-03-09 — Mobile interceptor strips custom error fields**: `transformError` in `interceptors.ts` only mapped fixed fields (`message`, `error`, `statusCode`, `errors`), discarding backend custom data like `quotes[]` array. → Spread the entire backend error response before overriding known fields.
- **2026-03-09 — Used Alert.alert for API errors instead of Toast**: Mobile quote wizard uses `Alert.alert` for all errors. Development rules require `Toast.show()` for API errors, reserving `Alert.alert` for confirmations/destructive actions only.
- **2026-03-09 — Massive file sizes unchecked**: `CreateQuoteWizard/index.tsx` grew to 2545 lines (limit: 500). Should have been split into orchestrator + step components + hooks per wizard rules. Always check file size before adding to existing files.
- **2026-03-09 — Loan controller missing @OrganizationContext()**: All CRUD endpoints in `loan-application.controller.ts` lacked org isolation. Any authenticated user could access/modify any tenant's loan data. → Every controller must have `@OrganizationContext()` on all endpoints; verify during code review.
- **2026-03-09 — Payment number generation skips soft-deleted rows**: `getNextPaymentNumber` omitted `.withDeleted()`, risking duplicate payment numbers identical to the quote number bug. → Audit all `generateXxxNumber` / `getNextXxxNumber` methods for `.withDeleted()`.
- **2026-03-09 — Debug console.log left in production web code**: `quote-builder.tsx` had 3 `console.log('[DEBUG-084c98]')` statements merged to main. → Always clean up instrumentation in the same PR; grep for debug markers before closing.
- **2026-03-09 — LoanService missing organizationId on all API calls**: All `LoanService` methods called backend endpoints without `organizationId`, causing 400 errors. Other services (PropertyService) already had this pattern. → When adding a new API service, check how existing sibling services pass `organizationId` (query param or header) and replicate consistently. Audit all endpoints in a service, not just the one that failed.
- **2026-03-10 — Migration phone normalization missed 12-digit numbers**: Migration only normalized 10-digit phones but `normalizePhone()` also handled 12-digit `91XXXXXXXXXX` → `+91XXXXXXXXXX`. → Always keep migration normalization logic in sync with application normalization functions; test both paths.
- **2026-03-10 — Migration CREATE UNIQUE INDEX not idempotent**: `CREATE UNIQUE INDEX` without `IF NOT EXISTS` fails on re-run. → Always use `IF NOT EXISTS` for index creation in migrations; `down()` already used `IF EXISTS`.
- **2026-03-16 — Duplicated subsidy list file content**: Accidentally ended up with duplicated component content, triggering lint errors. → When patching large files, re-open and verify no duplicate sections before running lint.
- **2026-03-16 — Zod defaults mismatched form types**: Using `.default()` on required booleans/records caused resolver type mismatches in `useForm`. → Keep schema required and set defaults in `useForm` values instead.
- **2026-03-23 — Unassign used `??` instead of explicit null check**: `assigneeId ?? undefined` evaluates to `undefined` when `assigneeId` is `null`; TypeORM skips `undefined` fields and never writes NULL to the column. → Always use `field === null ? null : field` when a nullable DB column must be explicitly cleared.
- **2026-03-23 — invalidateQueries in assign mutation triggered spurious list refetch**: `useAssignCustomer.onSuccess` called `invalidateQueries` on `customerKeys.lists`, which immediately refetched the background customer list page (it had active observers). → Only invalidate lists from mutations that change list membership/ordering (create, delete, status); use `setQueryData` alone for single-record field updates like assignee.
- **2026-04-09 — New shared component violated 7 frontend rules at once**: `advanced-table` used custom `debounce` (instead of `useDebounce` from `@/lib/hooks`), inline `new Date().toLocaleDateString()` (instead of `formatDate`), inline SVG data URI (instead of `@mui/icons-material`), `React.Fragment` namespace import (instead of named `Fragment`), `console.log` in example, arbitrary `fontSize: '0.8125rem'` literals (instead of MUI theme variants), and helper sub-components placed before the exported main component. → Before writing a new shared component, run through the full `frontend.mdc` Never/Always checklist: existing hooks first, lib/utils for formatting, icons-material for icons, named React imports, public API at top of file, no console.log.
- **2026-04-23 — Used `gh` instead of GitHub MCP for PR creation**: Tried CLI PR flow and hit auth failure despite available GitHub MCP tools. → For GitHub tasks, use MCP (`get_me` first, then create/list/search tools) and fallback only if explicitly requested.
- **2026-04-23 — Used undefined Tailwind class `bg-surface` across panels**: Tailwind silently dropped the class → panels rendered with transparent background ("no card" feel). → Before using color/utility class names, verify the token exists in `tailwind.config.ts`; prefer existing tokens (`bg-card`, `bg-background-secondary`) or add the token explicitly.
- **2026-04-23 — Activity feed "View full log" linked to `?tab=activity` (Coming Soon placeholder)**: Tab exists in URL routing but renders `ProjectComingSoonTab`. → Always verify that linked tabs render real content, not placeholders. The activity content lives on the summary tab.
- **2026-04-23 — Overview milestones showed stale entity `status` instead of task-derived status**: `usePaymentMilestones` returns `milestone.status` from the project entity, which the backend doesn't auto-update when tasks complete. Summary API computes correct progress from tasks. → When task-completion data is available, derive effective milestone status from `completedTasks/totalTasks` rather than trusting the stored entity status.
